# F-43 — Observed cases that PO 7.5 and CPI cannot settle become `decided`

- **Assumption** (ADR-0018, "Observed cases"): every assumed case ends as `observed`, because PO 7.5 and CPI
  answer it, and where they differ PO 7.5 wins.
- **How it fails**: the observation run (#213, table in the #212 comment "Observation run vs assumed corpus
  cases") cannot answer four groups of cases. The owner decided them on 2026-11-13 (#212 comment "Owner
  decisions"):
  1. **Time zone** (`fn/dateTrans/003`, `004`, `005`, `012`, `fn/compareDates/004`): PO and CPI ran in their
     own environment zones, not in UTC, so the UTC precondition of the case was not met. The time zone of a
     run is the service's (UTC by default). The parts observed in UTC are cited as partial evidence.
  2. **Counter** (`fn/counter/001`-`003`): the counter has no input on PO or CPI, so the graph is not drawable
     and obs-statistic is `NOT_RUN`. These cases are Flottila's own extension. The same holds for
     obs-ifwithoutelse `iwe-1` and obs-shared-box.
  3. **JSON null** (`structure/jsonNull/001`): not run (excluded by the owner's prompt). ADR-0008 stays the
     reading; it is observed again with the JSON spec.
  4. **PO and CPI disagree, Flottila follows CPI** (`fn/sort/004`, `fn/sortByKey/002`, `fn/fixValues/002`):
     the expected output equals the CPI output. The PO difference becomes a catalogue deviation, with its
     note in the tooltip only (ADR-0028). Where PO differs:
     - `sort`, `sortByKey`: string order. PO puts 😀 before ﬀ and Ａ (`z, 😀, ﬀ, Ａ`; `sortByKey` gives
       `2,4,1,3,6,5` where CPI gives `2,4,1,3,5,6`).
     - `fixValues`: a fresh FixValues in PO defaults to "Use default value" (empty), so a key the table
       lacks gives an empty value.
- **Severity**: minor
- **Evidence**: #212 comments "Observation run vs assumed corpus cases" and "Owner decisions (2026-11-13)";
  `corpus/observations/obs-date`, `obs-statistic`, `obs-structures`, `obs-context-functions`, `obs-constant`;
  ticket #214.
- **Change made**: ticket #214 sets `provenance: decided` on the 12 cases above, with a `ref` that cites the
  decision and F-43. `fixValues` becomes `{level: "deviation"}` in the catalogue with the text "A fresh
  FixValues box in SAP PO gives an empty value for a key the table lacks ("Use default value"). Flottila
  gives the key itself, as SAP Cloud Integration does." `sort` and `sortByKey` keep `assumed` while a case
  of theirs is assumed (`fn/sort/012`, `013`, `fn/sortByKey/006`: SUPPRESS placement). The fix ticket that
  clears the last one sets them to `{level: "deviation", text}`, with these texts:
  - `sort`: "Compares text by Unicode character (code point). SAP PO puts 😀 before ﬀ and Ａ, so text with
    an emoji or another character beyond the Basic Multilingual Plane can sort differently."
  - `sortByKey`: "Orders keys as `sort` does, and case-insensitively by Unicode character. SAP PO puts 😀
    before ﬀ and Ａ and can order keys differently."
  Decision 4 departs from ADR-0018's "when they differ, PO 7.5 wins" for these three cases, by the owner's
  decision. The ADR text is not edited in this ticket (outside its paths); the architect amends ADR-0018
  with a pointer to F-43.
