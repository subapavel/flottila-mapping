# F-51 — A constant fed into a context function is written into every Item

Status: open

- **Assumption** (ADR-0004:65): a constant fed into a context or queue function is a queue of one
  context with one value, so it reaches the first Item only.
- **How it fails**: `obs-lift-reuse` lift-4: PO 7.5 and CPI both write `W = k` in all three Items (V = 1
  only in Item 1, from `count`). PO's display queue shows the constant as a gray start row and a dark-gray
  terminal row, with no extra ordinary value.
- **Severity**: major
- **Evidence**: `corpus/observations/obs-lift-reuse/{po75,cpi}/l4-lift-4.xml`, `po75/lift-4-queues.txt`,
  `l4.xml`; #212 comment "Owner decisions (2026-11-13, second set)", point 3; ticket #221.
- **Change made**: none now. No case changes. A new corpus case and the fix come after milestone 1; ADR-0004
  is amended with that fix.
