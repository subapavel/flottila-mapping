# F-52 — `attr4`: CPI prefixes a qualified attribute `ns1`, PO `ns0`

- **Assumption** (ADR-0022:10, :35): the target root's namespace gets the prefix `ns0`, as PO does.
- **How it fails**: `obs-structures` attr4 (namespace `urn:flottila:obs:attr`): PO writes
  `<ns0:Flagged xmlns:ns0="urn:flottila:obs:attr" ns0:flag="" ns0:code="X1">`, CPI
  `<ns1:Flagged xmlns:ns1=... ns1:code="X1" ns1:flag="">`. The prefix and the attribute order differ; the
  qualified names are the same.
- **Severity**: minor
- **Evidence**: `corpus/observations/obs-structures/{po75,cpi}/attr4-str-attr-ns.xml`,
  `attr4-str-attr.xml` (no namespace: same on both apart from attribute order); #212 comment "Owner decisions
  (2026-11-13, second set)", point 4; ticket #221.
- **Change made**: none. ADR-0022 stays (`ns0`). The CPI difference is a serialization difference only:
  prefix and attribute order are not part of the XML infoset the cases compare.
