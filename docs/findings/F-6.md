# F-6 — three details of the `formatVersion` 1 schema that ADR-0010 and ADR-0011 got wrong

- **Assumption** (ADR-0010, ADR-0011):
  - every object closes with `additionalProperties: false`;
  - a `udfs` entry requires `inputs`;
  - Jackson binds the records.
- **How it fails** (designer draft for #24):
  - A table parameter's keys are source values, so it cannot close.
  - The canonical writer leaves out empty arrays, so a UDF with no inputs needs `inputs` optional.
  - ADR-0016's enforcer bans `com.fasterxml*` in `engine/`, so Jackson is not on the engine's path.
  - `wsdl.interface` is a Java keyword, so its record component cannot share the name.
- **Severity**: minor
- **Evidence**: #24 design draft, 2026-10-31, architect-approved.
- **Change made**:
  - ADR-0011 now says a table closes with `additionalProperties: {type: string}`, and the closure test lists it as the one exception.
  - The record component for `wsdl.interface` is `interfaceName`, and the drift test has one alias for it.
  - ADR-0010 marks `udfs.inputs` optional.
  - Binding is hand-written over json-sKema's parsed tree. ADR-0011 §Consequences no longer names Jackson for the engine.
  An empty table parameter is a value, so the writer keeps it as `{}`; ADR-0010 §Canonical form
  names that exception.
