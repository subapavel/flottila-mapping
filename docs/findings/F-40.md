# F-40 — the results of a gate commit cannot be in that commit's `bench/RESULTS.md`

- **Assumption** (`.claude/skills/gate/SKILL.md` steps 1–3): the gate pins one commit, and its
  numbers go to `bench/RESULTS.md` with that commit.
- **How it fails**:
  - A commit that adds the results to `bench/RESULTS.md` is a later commit, and a later commit is a
    new gate run.
  - The gate-reviewer found check 7 met on 7b4fadd but not yet in `bench/RESULTS.md`.
- **Severity**: major
- **Evidence**: #198 (gate verdict, check 7), #205.
- **Change made**:
  - `/gate` writes the gate run's measurement into `bench/RESULTS.md` on branch `gate/<milestone>`,
    with `HANDOVER.md` if it changed.
  - The gate-reviewer reads them there.
  - `.claude/skills/gate/SKILL.md` step 3 is changed.
