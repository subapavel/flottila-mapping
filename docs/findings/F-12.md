# F-12 — No reference resolver port: the service alone guards bundle paths

Status: closed (#90, merge 36e6267 on `spec/89-structures`, 2026-11-05; spec #89).

- **Assumption** (ADR-0014, References): structure files are read through a `ReferenceResolver` port that the
  host supplies. A package reference gives the design-time error "package references need a host resolver".
  The facade applies the test timeout (ADR-0016), `flottila:TIMEOUT` after 10 s.
- **How it fails**:
  - There is no port. `StructureReader` reads `base.resolve(file)` unchecked, so an absolute reference is
    read as it is.
  - The service's workspace check runs before the engine's read. That leaves a check-then-read gap, and
    other callers of `Structures.load` get no guard at all.
  - There is no catalogue code for a package reference.
  - `EngineFacade.run` has no timeout.
  - The `schema-unreadable` message carries `IOException.toString()`, so it shows an absolute server path.
- **Severity**: major (security boundary), mitigated in spec 1. The service binds to 127.0.0.1 and refuses
  every workspace escape before the call (ADR-0024).
- **Evidence**: #28 design; `engine/structure-import/.../StructureReader.java:55`.
- **Change made**: none in spec 1. Spec 4 (structures, references and refresh) carries:
  - the port;
  - the package-reference code;
  - a message relative to the bundle.
  Spec 2 carries the timeout, with the trace in the test response. The timeout is applied by #54
  (`EngineFacade.testRun`); the trace comes with #53.
- **Decided** (spec-4 grilling, 2026-11-05): ADR-0014 "Decided for spec 4" gives the port, the package-reference
  code `package-reference-unsupported` and messages relative to the bundle. ADR-0024 lets package references pass
  the pattern. The finding closes when the spec-4 ticket that builds the port merges.
- **Closed** by #90, merge 36e6267 on `spec/89-structures` (2026-11-05):
  - `ReferenceResolver` is the only way the engine reads a file; ArchUnit rule F, ADR-0016.
  - The service's `Workspace.resolver` checks and reads one reference in a single step, so there
    is no gap between check and read.
  - `package-reference-unsupported` is in the catalogue.
  - `schema-unreadable` names the reference as the bundle spells it, never an absolute path.
