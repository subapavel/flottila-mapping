# F-1 — json-sKema also validates the mapping model

- **Assumption** (ADR-0008, §Readers): "The module `structure-import` alone sees the reader libraries."
- **How it fails**: the mapping-model format (#6, ADR-0011) needs a JSON Schema 2020-12 validator.
  json-sKema 0.32.0 is one (observed on JDK 25, 2026-10-30). A second validator library would
  add a dependency and a second error format.
- **Severity**: minor
- **Evidence**: grilling #6 (owner agreed, 2026-10-30). Scratch run of json-sKema's
  `Validator.validate` on a 2020-12 schema with `$defs`, `oneOf` + `const` and
  `additionalProperties: false`: VERIFIED_PASS (not committed).
- **Change made**: ADR-0008 §Readers now says `structure-import` is the only module that uses
  the reader libraries to read structures. The mapping-model module uses json-sKema to validate
  mapping models. The intent is kept: reader libraries never leak into the structure records or
  the compiler.
