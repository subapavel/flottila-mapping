# F-28 — The tree, not the wire, derives a refused field's inherited refusal

- **Assumption** (ADR-0027 "Refused fields on the wire"): "`FieldDto` gains an optional
  `refusal {code, file, line, column}` … A field below a refused field carries the refusal nearest the root."
- **How it fails**: types share fields, so one `FieldDto` can sit below a refused field in one place and not in
  another, and a refusal can hold for the target only (`Refusal.Reason.targetOnly()`). The wire therefore
  carries each field's own refusal plus `side` (`both` | `target`), and the structure overview derives the
  nearest-root refusal per row and per side (`rowRefusal`, used by `treeRows` and `filteredRows`).
- **Severity**: minor (same behaviour for the author; the wire shape differs from the ADR's text)
- **Evidence**: `service/src/main/java/io/flottila/mapping/service/RefusalDto.java`,
  `ui/src/editor/structure-overview/rows.ts`; #116 evidence comment 6681840284; spec 5 review round 1.
- **Change made**: none to the code. The owner declined amending ADR-0027 in this run; the ADR wording is
  owner question #129. The spec 5 PR names it as a deviation.
