# F-34 — ADR-0013 and ADR-0019 still name the old editor's paths

- **Assumption** (ADR-0013 line 11 and §Coverage, ADR-0019 lines 20 and 76):
  - the UI's only public entry is `MappingEditor` in `ui/src/editor/index.ts`;
  - the store's coverage floor and ratchet row are on `ui/src/editor/store`.
- **How it fails**:
  - spec #152 replaced the editor with the Mapping studio (ADR-0028);
  - #161 deleted `ui/src/editor/` and moved the store to `ui/src/studio/store`;
  - the public entry is now `Studio` in `ui/src/studio/shell/Studio.tsx`;
  - the ADRs were not amended, so they name paths that no longer exist.
- **Severity**: minor. Code and gates already use the new paths:
  - `scripts/ratchet.java`;
  - `ui/vitest.config.ts`;
  - `docs/GATE.md`, `docs/WORKFLOW.md` and `ratchet/README.md`.
- **Evidence**: the spec #152 review, round 1 (Spec axis, item 2).
- **Change made** (2026-11-10, owner approved): ADR-0013 and ADR-0019 got a dated amendment in their status line. It names `Studio` and `ui/src/studio/store`, and says that the old paths below read as these. The decisions are unchanged, and the body text is left as it was.
