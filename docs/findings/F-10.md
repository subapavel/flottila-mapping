# F-10 — The diagnostic catalogue test cannot run under PIT

- **Assumption** (ADR-0018, F-9): the catalogue check runs as an api unit test, the same way under every runner.
- **How it fails**: `DiagnosticCatalogueTest` reads `ModuleLayer.boot()`. PIT puts the modules on the class
  path, so that layer is empty and PIT reports "2 tests did not pass without mutation". The api mutation run
  then fails before it mutates anything.
- **Severity**: minor
- **Evidence**: #26 hand-back, `.logs/26-pit-api.log` on `t/26-compile-run`.
- **Change made**: `engine/api/pom.xml` excludes `DiagnosticCatalogueTest` from PIT only, with a comment
  pointing here. Surefire still runs it in every build. The test covers no api main code, so mutation scores
  do not change.
