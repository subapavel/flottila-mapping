# F-21 — A generating function is a graph with no source field and a single-value result

- **Assumption** (ADR-0006, "A **generating function** (a function graph with no source field) on a target becomes `TargetRepeat`"; GLOSSARY "Generating function"): every function graph without a source field repeats per parent occurrence.
- **How it fails**: since #83 a box lowers to a queue or a single value. A graph with no source field whose result is a queue, such as `count(constant)`, is a queue (the constant enters `count` as `AtomicToQueue`, one context with one value) and maps through `TargetSlots` like any queue: `fn/constant/006` gives V in Item 1 only. Only a single-value result becomes `TargetRepeat`. The definition was wider than the lowering and the approved case.
- **Severity**: minor
- **Evidence**: #83 spec review (reviewer-spec, non-blocking 1), case `fn/constant/006` (assumed, `obs-constant` row), `Lowering.single`, `GoldenCorpusTest.checkResultEntry`.
- **Change made**: ADR-0006 amended and GLOSSARY "Generating function" narrowed: a function graph with no source field whose result is a single value. A graph with no source field that yields a queue maps as a queue. Behaviour unchanged; the observation request `obs-constant` already covers both readings.
